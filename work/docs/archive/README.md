# Archive

Process artifacts that have been superseded but are worth keeping: stale research notes, earlier plans, retired drafts. Rules are in [CONTRIBUTING.md § Research notes](../../../CONTRIBUTING.md#research-notes).

Each archived file starts with a line saying why it was archived and what replaced it. Decision records are never archived; a superseded decision stays in [decisions/](../decisions/README.md) with status `Superseded by NNNN`.
